01 / Fonctionnalités

Tout ce qu'il faut.
Rien de superflu.

Un gestionnaire pensé pour les téléchargements du quotidien et les fichiers volumineux.

01 / PERFORMANCE
↯

Téléchargements segmentés

Répartit les fichiers en plusieurs segments HTTP pour utiliser plusieurs connexions lorsque le serveur le permet.

02 / FIABILITÉ
↺

Pause & reprise

Reprend les téléchargements interrompus après une pause ou un redémarrage, si le serveur prend en charge la reprise.

03 / NAVIGATEUR
◎

Extension Chrome

Capture les liens depuis Chrome et transmet les téléchargements à Rapido.

04 / VIDÉOS
▷

Capture vidéo

Détection de certains flux vidéo compatibles et choix de qualité grâce à yt-dlp. Pas de contournement DRM.

05 / ORGANISATION
▦

File d'attente

Organisez et programmez vos téléchargements à l'heure qui vous convient.

06 / CONTRÔLE
◈

Vitesse & catégories

Limitez la bande passante et classez les fichiers automatiquement selon leur type.

02 / Philosophie

Votre PC.
Votre outil.

Pas d'abonnement, du code consultable et une application qui s'exécute sur votre machine.

02 / Expérience Windows

Une application de bureau.

Fenêtres WebView2, icône dans la zone de notification et API locale sur 127.0.0.1 : Rapido fonctionne sur Windows, sans service de téléchargement distant requis.
