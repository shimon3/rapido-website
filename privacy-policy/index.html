Privacy Policy

Last updated: October 18, 2026

This policy describes privacy considerations for Rapido, an open-source Windows download manager, its browser extension, and the Rapido website. It reflects the publicly documented design of the project. Features and practices may change with future releases.

1. Data processed by the desktop application

To carry out downloads, Rapido processes download URLs, file names, selected destination folders, progress/history, preferences, and technical request information. Its documented architecture runs a local API on 127.0.0.1 and performs downloads on your computer, rather than through a Rapido-hosted download service. Local download data may remain stored on your device until you remove it.

2. Browser extension and permissions

The browser integration may inspect download links and supported media requests, then pass relevant URLs, referrer information and, when required for authenticated downloads, session cookies to the local Rapido application. These values are used to execute user-requested downloads. The project's security documentation states that session cookies are scoped to their destination, protected using Windows DPAPI when temporarily persisted, and cleared when the download completes.

3. Communication with third parties

When you request a download or video extraction, your computer connects to the source website or its supporting services. Those sites can receive ordinary network information such as your IP address and HTTP requests and may apply their own privacy policies. Rapido's website links to GitHub for source code and software downloads; GitHub and Cloudflare may process visit and delivery data under their own policies.

4. Website data

The Rapido website stores your selected display language in your browser's local storage. The site is hosted on Cloudflare Pages. Hosting infrastructure may process technical request information needed to deliver and protect the site. This policy does not claim that every hosting-layer log or cookie is disabled.

5. Retention and user controls

Download history, temporary files, application settings and downloaded files may be kept on your device according to the application's behavior and your choices. You can manage downloads and stored files using the application's controls and Windows. You may also clear this website's local storage using your browser settings.

6. Security

Rapido's publicly documented protections include restricting its local API, validating requests, and limiting how browser cookies are used. No software or network connection can guarantee absolute security. Review the open-source project documentation for the latest technical details.

7. Children and sensitive information

Rapido is a general-purpose download utility and is not designed to collect personal information directly from children. Avoid submitting sensitive personal information through issue reports or other public support channels.

8. Changes

This page may be updated when the website, desktop application, browser extension, or related data practices change. The revision date above will be updated accordingly.

9. Questions and contact

For privacy-related questions, contact the project maintainers via the official GitHub issue tracker. Do not post passwords, session cookies, private URLs, or other sensitive data in a public issue.
